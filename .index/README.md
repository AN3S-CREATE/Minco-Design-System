# Minco project context index

Living context for humans and agents. Read before coding; update after structural changes.

## Files

| File | Purpose |
| --- | --- |
| `file-inventory.md` | Paths, purpose, status |
| `architecture.md` | System overview |
| `key-decisions.md` | ADR-style decisions |
| `dead-code.md` | Unused / legacy notes |
| `context-refresh-log.md` | Refresh history |

## Rules

- Descriptions must come from reading real files.
- Relative paths from repo root.
- No secrets.
- After creates/edits/deletes: update inventory (and architecture/decisions if needed).
